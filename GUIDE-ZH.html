Agent Alpha Hunter：使用指南

更新于 2026-10-24 · 作者 x : @HoangFUDSCAM · Tiếng Việt · English

机器人能做什么

Agent Alpha Hunter 运行在你自己的电脑上，用于发现并铸造 BNB Chain 上的 "alpha" NFT。所有交易都通过 Binance Agentic Wallet 完成。机器人绝不会索要助记词或私钥。

  • 发现热门 NFT：扫描链上正在大量铸造的 NFT，统计铸造者中持有 Agent ID (.ai) 的比例，并结合 X 和 gang.fun 的信号。
  • 铸造前显示完整信息：合约价格、其他人支付的价格、当前售价、预估利润、实时已铸造数量、每钱包上限、安全分 0–100。
  • 每个 NFT 的项目规则（来自合约和项目网站），以及项目的 X 链接。
  • 一键铸造：选择数量，点击 Mint，确认。还有"等待开放铸造"按钮，开放时提醒你确认。
  • 出售与清理：为持有的 NFT 查找最高售价，直接从 Agentic 钱包在 Element 挂单（可自动挂单），检查 gang.fun 代币的流动性（LP）是否已锁定或销毁，查看并撤销代币授权。
  • 🔥 Hot（0–100）表示项目热度（铸造钱包数、Agent ID 比例、X 提及），不是安全分。💎 宝藏表示仅限 Agent ID、铸造较慢、知道的人还不多的项目。
  • 仿冒提醒：两个合约同名时，铸造较少的那个会显示红色"可能是仿冒"警告。
  • 自动学习铸造方式：合约使用特殊铸造函数时，机器人会复制他人成功铸造的调用（替换成你的钱包和 Agent ID）。每次铸造仍需你确认。
  • VPS 模式 + Telegram 提醒：无界面终端模式（见下文）。
  • 三种语言：右上角 VI / EN / 中文 按钮。

准备工作

  1. Node.js 20 或更高版本：在 nodejs.org 下载 LTS 版本并正常安装。
  2. Binance Agentic Wallet：在 Binance App 中开通，并充值少量 BNB 用于 gas 和铸造费用。在 App 中为 Agentic Wallet 开启 Developer Mode，否则机器人无法发送铸造交易。
  3. Agent ID (.ai)：很多项目只允许持有 Agent ID 的钱包铸造。如果你的钱包没有，机器人会提示。
  4. 建议：在 Binance App 中为 Agentic Wallet 设置较低的 Daily Limit。这是 Binance 端的安全措施，不依赖机器人。

安装与运行

  1. 把 nft-alpha-bot.zip 解压到一个文件夹，例如 C:\nft-alpha-bot。
  2. 启动：Windows 双击 start.bat；Mac 双击 start.command（如被系统拦截，右键文件选择"打开"）。
  3. 首次运行会自动安装依赖库和 Binance 的 baw 钱包工具，约需 1–2 分钟。
  4. 浏览器会自动打开 http://127.0.0.1:3777。若未打开，请手动访问该地址。
  5. 使用期间保持黑色命令行窗口开启，关闭它就会停止机器人。

更新版本：把新版本解压覆盖旧文件夹即可。data 文件夹（支出记录、私有 RPC、已发现的 NFT）会保留。

登录钱包并设置私有 RPC

登录：点击页面顶部的登录钱包。机器人会显示链接和配对码；打开链接，核对配对码一致后在 Binance App 中确认。完成后钱包标签变绿并显示余额。如果提示缺少 baw，先点击安装 baw。

私有 RPC（建议）：免费公共 RPC 经常过载，导致扫描慢或找不到 NFT。免费私有 RPC 只需 2 分钟：

  1. 打开 NodeReal，用 Google 或 GitHub 注册。
  2. 点击 Create API Key，任意命名。询问 Discord 时点击 Skip。
  3. 打开新建的 key，点击 BSC RPC → Endpoint，复制 Mainnet HTTPS 链接，形如 https://bsc-mainnet.nodereal.io/v1/...。
  4. 在机器人中打开 ⚙ 私有 RPC，粘贴链接，点击测试并保存。顶部 RPC 标签显示"（私有）"即完成。

RPC 只用于读取链上数据，无法动用你的钱包。链接包含 API key：不要分享，也不要截图。

在 Element 挂单出售（Agentic 钱包）

Agentic 钱包无法连接 Element 网站，所以网站上没有挂单按钮。机器人代你挂单，挂单照常显示在 Element 上。

  1. 在 Element 申请表 https://forms.gle/78wpggURGADCjshr7（咨询：api@element.market）免费获取 Element API key，粘贴到出售区的 Element API key 框 → 保存。
  2. 点击 查找最高售价。每个 NFT 都有价格框（已填建议价）和 挂单 按钮。
  3. 每个系列第一次：第 1/2 步授权 Element 在有人购买时转移 NFT（少量 gas）。机器人只允许授权给 Element 交易合约 0xb3e3DfCb2d9f3DdE16d78B9e6EB3538Eb32B5ae1。
  4. 确认框显示价格、平台费、版税和你实际到手的 BNB → 签名并挂单（无需 gas）。

自动挂单（默认关闭）：勾选后设置相对铸造价的加价 %、底价和天数 → 保存。机器人每 15 分钟为未挂单的 NFT 挂单，价格取以下最高者：近期成交中位价、铸造价 + 加价、底价。没有参考价则不挂单。VPS：node src/index.js element-key --key KEY，然后 node src/index.js autosell --on --markup 30 --min 0.01。

在 VPS（终端）运行并推送到 Telegram

适合在无图形界面的 Linux VPS 上 24/7 运行。此模式下机器人只扫描并提醒热门 NFT / 💎 宝藏项目到 Telegram，不会铸造；看到合适的项目后，请在电脑上用网页界面照常铸造。

  1. 创建 Telegram 机器人：给 @BotFather 发送 /newbot → 取名 → 复制 token（123456:ABC...）。打开新机器人并随便发一条消息（如需推送到群组，把机器人拉进群并在群里发消息）。
  2. 在 VPS 上安装（Ubuntu/Debian）： 
    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git
git clone https://github.com/Hoangstephen/agent-alpha-hunter
cd agent-alpha-hunter && npm install
  3. 连接 Telegram（自动获取 chat id 并发送测试消息）：node src/index.js telegram-setup --token 123456:ABC...
  4. 私有 RPC（建议）：mkdir -p data && echo '{"url":"https://bsc-mainnet.nodereal.io/v1/你的KEY"}' > data/rpc.json
  5. 试运行：npm run vps（每 5 分钟扫描一次；可用 node src/index.js vps --every 3 修改）。按 Ctrl+C 停止。
  6. 后台 24/7 运行： 
    sudo npm i -g pm2
pm2 start src/index.js --name alpha -- vps --every 5
pm2 save && pm2 startup     # VPS 重启后自动运行
pm2 logs alpha              # 查看日志

data/telegram.json 中的选项：minHot（默认 50：只提醒 Hot 分 50 以上的 NFT，宝藏项目总会提醒）、lang（vi / en / zh）、repeatHours（默认 6：同一 NFT 6 小时内不重复提醒）。安全分低于 40 的 NFT 会被跳过，可能的仿冒会明确标注。运行过 telegram-setup 后，电脑上的网页界面也会推送 Telegram 提醒。

Telegram 机器人 token 保存在 data/telegram.json：请勿分享或上传到 GitHub（data 文件夹已被 git 排除）。

安全与限制

  • 绝不索要或保存助记词、私钥。由 Binance 为钱包签名。
  • 绝不自动铸造：每次铸造都需要你点击确认。
  • 支出上限：每次最多 0.05 BNB，每天最多 0.2 BNB（可在 config.json 中修改）。
  • 拦截盗币合约常用的调用：setApprovalForAll、transfer、permit，以及金额不符的 approve。如果 Binance 模拟发现交易向他人授权，也会拦截。
  • 安全分低于 60：必须勾选"我已自行检查合约"才能铸造。低于 40：始终拦截。
  • 界面只在你的电脑上运行（127.0.0.1），其他网站无法调用。

注意：安全分只是粗略筛选，不是认证。翻译的项目规则是对项目方文字的机器翻译。不要把助记词粘贴到任何地方，包括"客服"或 AI。
