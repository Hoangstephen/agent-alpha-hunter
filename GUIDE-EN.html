Agent Alpha Hunter: User Guide

What the bot does

Agent Alpha Hunter runs on your own computer to find and mint "alpha" NFTs on BNB Chain. Every transaction goes through Binance Agentic Wallet. The bot never asks for your seed phrase or private key.

  • Finds hot NFTs: scans NFTs being minted heavily on-chain, measures what % of minters hold an Agent ID (.ai), and adds signals from X and gang.fun.
  • Shows everything before you mint: contract price, what others are paying, current sale price, estimated profit, live minted count, per-wallet limit, safety score 0–100.
  • Project rules for every NFT, read from the contract and the project website, plus the project's X link.
  • One-click mint: pick a quantity, press Mint, confirm. A "wait for mint to open" button alerts you when minting starts.
  • Sell and clean up: find the best sell price for NFTs you hold, list them on Element straight from the Agentic Wallet (with optional auto-listing), check whether a gang.fun token's liquidity (LP) is locked or burned, view and revoke token approvals.
  • 🔥 Hot (0–100) shows how much attention a project gets (minting wallets, Agent ID ratio, mentions on X). It is not a safety score. 💎 Gem marks Agent-ID-only projects that mint slowly and few people know about yet.
  • Lookalike warning: when two contracts share a name, the one with fewer mints gets a red "possible fake" warning.
  • Learns how to mint: if a contract uses an unusual mint function, the bot copies the call from someone else's successful mint (swapping in your wallet and Agent ID). You still confirm every mint.
  • VPS mode + Telegram alerts: headless terminal mode (see below).
  • 3 languages: VI / EN / 中文 buttons at the top right.

Before you start

  1. Node.js 20 or newer: download the LTS version from nodejs.org and install it like any other app.
  2. Binance Agentic Wallet: enable it in the Binance app and deposit a little BNB for gas and mint fees. In the app, turn on Developer Mode for the Agentic Wallet, otherwise the bot cannot send mint transactions.
  3. Agent ID (.ai): many projects only allow wallets with an Agent ID to mint. The bot tells you if your wallet has none.
  4. Recommended: set a low Daily Limit for the Agentic Wallet in the Binance app. This is a Binance-side safety layer that does not depend on the bot.

Install and run

  1. Unzip nft-alpha-bot.zip into a folder, for example C:\nft-alpha-bot.
  2. Start the bot: on Windows double-click start.bat; on Mac double-click start.command (if macOS blocks it, right-click the file and choose Open).
  3. The first run installs libraries and Binance's baw wallet tool, which takes about 1–2 minutes.
  4. Your browser opens http://127.0.0.1:3777 automatically. If not, open that address yourself.
  5. Keep the black command window open while you use the bot. Closing it stops the bot.

To update: unzip the new version over the old folder. The data folder (spending log, private RPC, found NFTs) is kept.

Log in and set a private RPC

Log in: press Log in wallet at the top. The bot shows a link and a pairing code; open the link, check that the code matches, then confirm in the Binance app. The wallet pill turns green and shows your balance. If the bot says baw is missing, press Install baw first.

Private RPC (recommended): free public RPCs are often overloaded, which makes scans slow or empty. A free private RPC takes 2 minutes:

  1. Go to NodeReal and sign up with Google or GitHub.
  2. Press Create API Key and give it any name. If asked about Discord, press Skip.
  3. Open the new key, press BSC RPC → Endpoint, and copy the Mainnet HTTPS link, like https://bsc-mainnet.nodereal.io/v1/....
  4. In the bot, open ⚙ Private RPC, paste the link, press Test & save. The RPC pill at the top shows "(private)" when done.

The RPC only reads chain data and cannot touch your wallet. The link contains an API key: do not share it or screenshot it.

List NFTs on Element (Agentic Wallet)

Element's website shows no List button for the Agentic Wallet because that wallet can't connect to the site. The bot lists for you, and the listing shows on Element as usual.

  1. Get a free Element API key at Element's request form: https://forms.gle/78wpggURGADCjshr7 (questions: api@element.market), paste it into Element API key in the Sell section → Save key.
  2. Press Find best sell price. Each NFT gets a price box (pre-filled with a suggested price) and a List button.
  3. First time for each collection: step 1/2 lets Element transfer the NFT when someone buys (small gas fee). The bot only allows this for Element's exchange contract 0xb3e3DfCb2d9f3DdE16d78B9e6EB3538Eb32B5ae1.
  4. The confirm box shows the price, marketplace fee, royalty and the BNB you receive → Sign and list (no gas).

Auto-listing (off by default): tick it, set your markup over mint price, a floor price and days → Save. Every 15 minutes the bot lists NFTs not yet listed at the highest of: recent median sale price, mint price + markup, floor price. With no reference price it doesn't list. On a VPS: node src/index.js element-key --key KEY then node src/index.js autosell --on --markup 30 --min 0.01.

Sell on a project's own market (no Element needed)

  • Click Find best sell price. The bot finds the market where the collection trades (for example BN World's Onchain Agents market). A ✓ project market badge means the bot verified it: same owner as the NFT contract, listed on the project's site, or 5+ real buyers.
  • Reference prices (under the price column): the bot reads the cheapest live listing by other sellers on the project market (only unexpired listings whose seller still holds the NFT) and prices written on the project / market website (Floor, Price…). The suggested price never goes below that cheapest listing. Website prices may be outdated, double-check them.
  • Set sale price: the first time for each NFT the bot asks for approve(market, tokenId) for that NFT only, never the whole collection. The approval clears when it sells. Then it calls the market's list function. Every step is simulated and needs your confirmation.
  • Listed NFTs show "Listed … BNB on market … until …", read from the chain. If you see ⚠ "no approval for this NFT", click Approve this NFT: the existing listing becomes buyable, no need to list again.
  • Sell into an offer now only works when someone has an open offer. Unverified markets only get a link so you can sell on their website.
  • Revoke an NFT approval for a market: Token approvals → Revoke NFT rights (paste the NFT contract and the market address).

Run on a VPS (terminal) with Telegram alerts

For 24/7 hunting on a Linux VPS with no GUI. In this mode the bot only scans and alerts hot NFTs / 💎 hidden gems to Telegram and never mints; when you see a good one, mint it on your computer with the web interface as usual.

  1. Create a Telegram bot: message @BotFather → /newbot → pick a name → copy the token (123456:ABC...). Open your new bot and send it any message (for a group, add the bot to the group and send a message there).
  2. Install on the VPS (Ubuntu/Debian): 
    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git
git clone https://github.com/Hoangstephen/agent-alpha-hunter
cd agent-alpha-hunter && npm install
  3. Connect Telegram (finds your chat id and sends a test message): node src/index.js telegram-setup --token 123456:ABC...
  4. Private RPC (recommended): mkdir -p data && echo '{"url":"https://bsc-mainnet.nodereal.io/v1/YOUR_KEY"}' > data/rpc.json
  5. Test run: npm run vps (scans every 5 minutes; change with node src/index.js vps --every 3). Ctrl+C to stop.
  6. Run 24/7 in the background: 
    sudo npm i -g pm2
pm2 start src/index.js --name alpha -- vps --every 5
pm2 save && pm2 startup     # restart automatically after a reboot
pm2 logs alpha              # view logs

Options in data/telegram.json: minHot (default 50: only alert NFTs with a Hot score of 50+, Gems always alert), lang (vi / en / zh), repeatHours (default 6: the same NFT is not re-alerted within 6 hours). NFTs with a safety score below 40 are skipped and possible fakes are clearly flagged. The web interface on your computer also sends Telegram alerts once telegram-setup has been run.

The Telegram bot token is stored in data/telegram.json: do not share it or upload it to GitHub (the data folder is excluded from git).

Safety and limits

  • Never asks for or stores a seed phrase or private key. Binance signs for the wallet.
  • Never mints on its own: you press Confirm for every mint.
  • Spending caps: at most 0.05 BNB per mint and 0.2 BNB per day (change in config.json if needed).
  • Blocks calls drainers use: setApprovalForAll, transfer, permit, and approvals for the wrong amount. Also blocks if Binance's simulation sees the transaction granting permissions to someone else.
  • Safety score below 60: you must tick "I have checked the contract myself" to mint. Below 40: always blocked.
  • The interface only runs on your computer (127.0.0.1); other websites cannot call it.

Good to know: the safety score is a rough filter, not a certificate. Translated project rules are machine translations of text the project wrote. Never paste your seed phrase anywhere, including to "support agents" or AI.

Common problems

"Developer Mode is off": the Agentic Wallet's Developer Mode has an expiry; Binance turns it off when it expires (or when the wallet balance exceeds its limit). Turn it back on in the Binance app → Agentic Wallet → Settings → Developer Mode. The bot shows when it will turn off and warns 60 minutes ahead.
